Antes de trabajar, lee AI_CONTEXT.md.
Lee PROJECT.md, ARCHITECTURE.md y TASKS.md solo cuando sean relevantes para la tarea.
Lee CHANGELOG.md solo cuando necesites contexto sobre cambios recientes.
No inventes contexto ni dupliques documentación. Mantén la documentación sincronizada con el código:

* Si cambia la arquitectura, actualiza `ARCHITECTURE.md`.
* Si cambia el objetivo o alcance, actualiza `PROJECT.md`.
* Si cambia el estado de una tarea, actualiza `TASKS.md`.
* Si aparece una regla, convención o decisión importante, actualiza `AI_CONTEXT.md`.
* Registra cambios relevantes en `CHANGELOG.md`.

Prioriza siempre el código y la documentación existente como fuente de verdad.
